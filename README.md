# Wellspring

A small browser-based resource-allocation prototype inspired by charity: water.

## How to run locally

1. Open the folder in a browser.
2. Open `index.html` directly in a browser, or serve the folder with a simple local web server.
3. Press Start to begin the game.

## Files

- `index.html` — game shell and interface
- `style.css` — styling and animations
- `script.js` — game logic and balance settings

## Notes

This prototype is intentionally lightweight and function-first. The current design emphasizes challenge, budget pressure, and route selection rather than heavy visual polish.
